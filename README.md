## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/VaibhavJadhav-27/Data-Structures-and-Algorithms.git
   cd Data-Structures-and-Algorithms
   ```
2. Open a solution in the topic folder that interests you.
3. Most files use the `Solution` class and method signature expected by LeetCode. Submit them there or call the method from a local test harness. Some files include standalone examples; for those, run the file with Python 3. For example:
   ```bash
   python "Array/Two Sum.py"
   ```

There is no shared test runner or external package dependency at this time. Check solutions against their examples and relevant edge cases.
